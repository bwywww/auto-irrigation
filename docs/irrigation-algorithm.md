# 综合灌溉算法与最终启停条件

当前Nano执行多传感器经验控制：土壤决定是否需要补水，温度和昼夜微调每轮时长，雨水拥有停水优先权。不是精确需水量或蒸散模型；参数需结合真实水流和土壤响应验证。

## 公式

M为土壤相对湿度%，Ms为启动阈值（默认30），Mt为停止阈值（默认45），T为℃，L为估算lux。

```text
KT = clip(1 + 0.02 × (T − 25), 0.8, 1.2)
KL = 白天1.1；晚上0.9；待判断1.0
t秒 = clip(5 × max(0, Mt − M)/(Mt − Ms) × KT × KL, 2, 20)
```

仅满足开阀条件且M<Mt时执行公式，否则本次开阀时间为0。四舍五入到毫秒执行，本轮开启后不延时；下一轮使用新采样重新计算。温度无效时KT=1，光照无效时昼夜设为待判断、KL=1，保留对应异常提示。

L≥300进入白天，L≤200进入晚上，200<L<300保持上一状态；上电处于中间区间用待判断。L按`(18×ADC/(1023−ADC))^1.5`换算并保留一位小数，与主页一致。

| M / T / 昼夜 | 单轮计划 |
|---|---|
| 30% / 25℃ / 白天 | 5.500秒 |
| 30% / 25℃ / 晚上 | 4.500秒 |
| 20% / 30℃ / 白天 | 10.083秒 |
| 10% / 35℃ / 白天 | 15.400秒 |
| 有雨、门禁未通过或M≥Mt | 不开阀 |

以上是公式验证输入，不是实物浇水测量。5秒基准、2～20秒范围、温度与昼夜系数及300/200阈值集中在Config.h。

## 自动补水与停止

1. 上电关阀待机。配置通过、连续3次有效土壤采样、采样未超过3.5秒、雨水干燥确认通过且无锁定，才允许开启。
2. 用户启用自动后，M≤Ms建立补水过程；冷却结束才开启一轮。
3. 到本轮计划时间关闭，等待5分钟后重新评估。补水过程进行中，即使Ms<M<Mt仍可继续下一轮。
4. 任何时刻M≥Mt就关闭并结束补水过程；以后必须再次M≤Ms才重新开始。
5. 有雨、雨水异常、土壤首次无效均立即关闭并取消过程。模式切换、待机、复位或成功修改阈值也取消旧过程。

雨水实测干值0、湿值≥400。采用0/400参考后，ADC≥80停水；ADC≤43持续60秒解除雨水限制，计时期间>43重新计时。雨水限制保留运行模式但取消补水过程，恢复后的自动模式重新判断启动阈值和冷却，手动需要新指令。

手动按用户输入1～30秒执行，不采用上述自动公式，也不以45%为正常停止阈值。手动浇水5秒无心跳锁定；所有模式的连续开阀60秒保护、急停和土壤锁定保护保留。单次无效土壤读数立即停水，连续3次异常或土壤采样过期锁定。复位必须检查通过，成功回待机。

每次实际开阀后关闭开始5分钟自动冷却，手动不受自动冷却限制。自动不依赖网页连接；网页关闭后不会保存数据，手动由心跳兜底停水。

## V3与网页记录

V3在V2末尾新增`daylight,plannedMs,cycleActive`，依次为0待判断/1白天/2晚上、本轮计划毫秒、自动补水过程标志0/1。plannedMs仅自动开阀时非0；剩余时间仍使用原remainingMs。关闭后保留过程标志直到达到目标或被取消。

命令与确认仍为V1。网页兼容V1/V2历史，不为旧记录补造新字段，旧连接显示控制版本提示。新样本与CSV保存全部V3字段。继电器控制输出不代表真实水流或机械阀位。

## 实地测试顺序

先上传当前固件并刷新网页；保持雨水探头干燥60秒，通过手动5秒测试输出。自动模式用实际土壤读数观察本轮计划与剩余时间；在等待渗透期间继续观察湿度。分别验证有雨立即停止、中途再次滴水重计、急停与复位。只接继电器LED时不能验证土壤吸水闭环，实际电磁阀通水、流量标定和24小时运行仍待完成。
