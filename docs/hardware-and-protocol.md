# 智慧物联网自动灌溉：Nano + HC-08 + 网页

新版入口是 `firmware/smart_irrigation/smart_irrigation.ino` 和 `web/`，适用于经典 ATmega328P Nano、单区电磁阀及土壤、温度、光照、雨水四路模拟传感器。Windows Chrome / Edge 直接通过 Web Bluetooth 连接 HC-08。网页负责呈现、操作与存储，灌溉保护逻辑在 Nano 上独立运行。

完整的模块、硬件、配置、控制状态转移图和验收项目见 [功能与工作逻辑清单](features.md)。接线以本文和 Config.h 为准。

新增雨水模块的接线、干湿校准和后续灌溉公式见 [雨水保护与灌溉标定](rain-calibration.md)。**已按参考测量值启用雨水配置：干燥0、湿参考400；上电持续干燥60秒后允许按原条件灌溉。**

## 1. 启动网页

安装和启动步骤见 [项目首页](../README.md)。网页位于 `web/`，Windows 启动脚本位于 `scripts/start-web.ps1`。

## 2. 新版接线及默认门禁

| Nano | 连接 | 说明 |
|---|---|---|
| A0 | 电容式土壤传感器 AO | 模拟输出，不接 DO |
| A1 | 光照传感器 AO | 原始ADC上传；网页按提供的公式显示估算lux |
| A2 | 模拟温度模块 AO | 按线性公式：温度°C = ADC × 5.0 / 1023 × 100 |
| A3 | 雨水模块模拟输出 | 5V模块：VCC→5V，GND→GND；实测干燥0、沾湿400以上 |
| D3 | 继电器控制输入 | 当前高电平有效（RELAY_ACTIVE_LOW=false）；接实际阀前核实驱动/电源 |
| D6 | LED 经限流电阻 | 普通状态指示灯，不用于大功率补光 |
| D8 / RX | HC-08 TX | AltSoftSerial 在 Nano 的固定接收引脚 |
| D9 / TX | 经电平转换接 HC-08 RX | Nano 为 5V 逻辑，不可假设 HC-08 RX 耐受 5V |
| GND | 低压信号公共地 | 按驱动要求连接，阀负载独立供电 |

HC-08 裸模块与带底板模块的供电要求可能不同，必须核对实物。蓝牙 UART 9600，USB 调试 115200。D8/D9 不要误接到 USB 串口 D0/D1。AltSoftSerial 使用 Timer1，避免叠加 Servo 等 Timer1 库，D9/D10 PWM 也受影响。

电磁阀不能直接接 GPIO。补齐匹配阀电压、电流的直流电源、额定容量足够的继电器/驱动和感性负载续流保护。常闭阀通过继电器 COM/NO 触点连接，继电器释放时阀断电。核实输入有效电平及上电/复位期间硬件默认关闭状态；setup 先写关闭电平再配置 OUTPUT，但 bootloader 阶段高阻状态仍需由硬件保证。

Config.h 默认：

```cpp
constexpr bool ACTUATOR_VERIFIED = true;
constexpr bool RAIN_CONFIGURED = true;
constexpr bool SOIL_CALIBRATED = true;
constexpr bool LIGHT_CALIBRATED = false;
constexpr float TEMP_REFERENCE_VOLTS = 5.0F, TEMP_C_PER_VOLT = 100.0F;
```

执行器、土壤或雨水配置未通过均禁止开阀。保留现有执行器验证和700/400土壤配置；雨水配置已启用，端点0/400。温度按线性公式换算。主页显示湿度%、温度°C、估算照度lux和雨水状态，四路ADC集中在设置中。

## 3. 校准、编译与烧录

1. 保持执行器关闭，先接传感器和 HC-08。Arduino IDE 安装 Arduino AVR Boards 和 AltSoftSerial。本机验证版本为 AVR 1.8.8、AltSoftSerial 1.4.0。
2. 打开新版 ino，开发板选 Arduino Nano，处理器 ATmega328P，选择实物端口上传。部分兼容板须选 ATmega328P (Old Bootloader)。
3. 串口监视器设 115200，可看每秒 D 帧。HC-08 UART 需与固件 9600 一致，若曾修改，按实物手册处理。
4. 土壤已启用 `(700-ADC)/3`，即 SOIL_DRY_RAW=700、SOIL_WET_RAW=400；限制0～100%，V1协议取整数（舍去小数），例如550→50%、669→10%。显示和控制共用固件换算值。在实际探头上对照干湿读数，必要时调整端点。百分比是参考点之间相对值，不是体积含水率。有效 ADC 为6～1017，异常时不会硬套公式显示百分比。
5. 光照按图片公式 `lux≈(18×ADC/(1023−ADC))^1.5`，在网页以一位小数显示“估算照度”；例如720→279.7 lux。主页、历史曲线、CSV共用 measurements.ts 的换算；ADC达到1023或光照故障时不显示估算值。V1原有相对光照字段及其配置保留兼容，LIGHT_CALIBRATED不影响lux显示。近似照度需与照度计对照，不能仅凭公式保证准确度。
6. 温度采用线性换算公式 `float vol = n * (5.0 / 1023.0 * 100);`，n 为 A2 的平均 ADC，结果单位为°C。例如 n=64 得31.28°C，协议发送3128，网页显示约31.3°C。已移除旧 NTC 阻值/B值配置；公式本身不确定模块型号。对照温度计验证，若实测ADC参考电压不是5.0V，在 TEMP_REFERENCE_VOLTS 填实测值后重新烧录。保留V1协议125°C上限，超过上限标记温度异常，原始ADC仍上传；0 ADC按公式为0°C，不能仅靠该数值判断探头是否断线。
7. 雨水已按实测0/400配置且RAIN_CONFIGURED=true，上传当前程序即可。复测步骤见[雨水测试说明](rain-calibration.md)。上电后需连续干燥60秒、连续3次有效土壤采样及执行器检查通过，才允许启用自动/手动。上电不会自动浇水。

校准参数通过修改源文件并烧录配置。网页阈值只保存在 Nano RAM，重启恢复 Config.h 的默认 30/45；本版不使用 EEPROM 保存运行时设置。

## 4. 控制行为

当前执行[综合灌溉算法](irrigation-algorithm.md)：土壤触发补水过程，每轮2～20秒，温度和昼夜微调时长；关闭后等待5分钟再判断，达到停止湿度结束过程。

| 条件/操作 | 固件行为 |
|---|---|
| 上电、复位成功 | 关阀，进入待机 |
| 雨水达到湿阈值 | A3每250ms采样，检测后立即关闭自动/手动输出，保留模式；启动自动冷却 |
| 雨水持续干燥60秒 | 解除雨水限制；自动仍需满足湿度和冷却条件，手动需新的浇水指令 |
| 雨水未校准、采样异常或3.5秒过期 | 禁止开阀；RESET不能绕过雨水检查，重新获得干燥样本后需重新确认60秒 |
| 自动且湿度 ≤ 启动阈值 | 门禁、传感器、无锁定、冷却通过后开阀 |
| 自动且湿度 ≥ 停止阈值 | 关闭并结束补水过程；再次降至启动值才建立新过程 |
| 自动本轮时长结束 | 关闭并等待5分钟；过程尚未结束时继续向停止湿度补水 |
| 每次开阀后关闭 | 开始自动冷却计时，包括手动结束；手动操作不受自动冷却限制 |
| 连续开阀达到60秒 | 强制关闭并锁定，排查后显式复位 |
| 手动 WATER | 须手动模式且心跳有效；1～30秒，网页默认5秒 |
| 已开阀时重复 WATER | 同编号返回原确认不延时；新编号返回 BUSY |
| 手动浇水5秒无心跳 | 关阀并锁定失联故障 |
| 一次无效土壤读数 | 当次采样立即关阀；连续3次异常锁定 |
| 土壤故障恢复 | 连续3次有效且显式 RESET 后回待机 |
| 采样3.5秒无更新 | 锁定土壤采样故障 |
| 温度/光照异常 | 标记对应字段，不单独禁止土壤灌溉 |
| STOP | 关阀、锁定，RESET 后回待机，不恢复旧模式 |
| MODE 0 | 正常关闭回待机；已有锁定保留 |
| THRESH | 仅关阀时修改，0 ≤ 启动 < 停止 ≤ 100 |

LED：待机灭、监测慢闪、浇水常亮、故障/未通过门禁/急停快闪。环境传感器异常快闪优先于浇水常亮。

关闭网页、电脑休眠或浏览器冻结后，自动模式由 Nano 独立运行；手动由最后心跳起5秒超时关阀。在网页主动“断开”时会尝试结束手动模式，自动模式继续。网页显示继电器控制输出，没有阀位/水流反馈，不能证明机械阀实际动作。

## 5. 通信协议：数据V3，命令/确认V1

ASCII CSV，以 LF 换行结束，也接受 CRLF，含换行最多192字节。接收可处理分包、合包、超长帧；非法帧丢弃到下一换行再恢复。字段内不接受空格、CR、非 ASCII。

数据帧共26字段，在V2雨水字段后追加昼夜、本轮计划时长、补水过程标志。网页兼容旧V1的20字段和V2的23字段历史；旧固件缺少雨水保护时，网页禁止启用自动、手动及开始浇水：

```text
D,3,seq,uptime,soilRaw,soilPct,tempRaw,tempCenti,lightRaw,lightPct,validMask,mode,valve,led,faultMask,start,stop,ready,remainingMs,cooldownMs,rainRaw,rainState,rainDryRemainingMs,daylight,plannedMs,cycleActive
```

- seq、uptime 为无符号32位帧序号和 millis，可回绕。
- 三路 raw 为0～1023；soilPct/lightPct 为0～100，无效或未标定为-1；tempCenti 为摄氏度×100，无效/未配置为-32768。
- validMask 位1/2/4表示土壤百分比/温度/光照百分比有效，不是原始 ADC 是否存在。
- mode：0待机、1自动、2手动；valve：0关闭、1开启；led：0灭、1慢闪、2常亮、3快闪。
- ready 表示控制就绪；remainingMs 为本帧剩余浇水时间；cooldownMs 为自动冷却剩余时间。
- faultMask 位：1土壤、2连续超时、4急停、8手动失联、16温度、32光照、64配置未通过、128雨水限制、256雨水采样异常，可按位相加。
- rainRaw为0～1023；rainState：0待校准、1干燥、2检测到雨水、3等待干燥、4采样异常。rainDryRemainingMs为干燥确认剩余毫秒，仅状态3使用。雨水限制不是急停锁定，不改变模式；就绪必须同时满足雨水干燥。

daylight：0待判断、1白天、2晚上；plannedMs仅自动开阀期间为本轮固定计划时长，其他时间为0；cycleActive为0/1，表示自动补水过程是否仍进行。旧历史不补造这三个字段，CSV追加对应三列。

命令/确认示例，每行都需要发送换行：

```text
C,1,1,STATUS
C,1,2,MODE,2
C,1,0,HB
C,1,3,WATER,5
C,1,4,STOP
C,1,5,RESET
C,1,6,THRESH,30,45
A,1,6,OK
```

HB 固定编号0，不回复 ACK。其他命令编号1～4294967295，正常操作使用新编号，重试使用完全相同的编号和内容。USB 也支持此协议，避免两个控制端同时发浇水命令。

ACK 为 A,1,id,result。结果支持 OK、BAD_COMMAND、BAD_ARGUMENT、NOT_READY、LOCKED、BUSY、NEED_MANUAL、NEED_HEARTBEAT、ID_CONFLICT、QUEUE_FULL。语法/参数非法帧直接丢弃，不保证 ACK。ACK 队列满时普通命令不执行，STOP 仍执行。网页收到 ACK 才报告成功，2秒无确认则同编号重试一次，再失败显示确认超时。

固件用12条有界结果缓存去重，心跳不占缓存，覆盖网页单命令在途、一次重试的约定。缓存不跨重启，也不是无限历史日志，不应在执行许多新命令后重放旧帧。重复 STOP 仍关闭输出。断连清空待执行指令，重连重新获取服务/特征，只发心跳、查询当前状态。

BLE 每片最多20字节，片间20ms，片和帧均串行；按特征能力选择有/无响应写入。固件控制/接收/LED 无 delay；USB 按可用缓冲空间发送，AltSoftSerial 每隔至少1250微秒发送一个字节，处理停止不等待整帧发完。AltSoftSerial 1.4.0 未实现 availableForWrite()，不能用该返回值作为蓝牙发送条件。

若旧固件的 USB 只输出第一条 D 帧，且 STATUS 与网页连接均确认超时，请重新上传当前修复版。旧代码错误地等待 AltSoftSerial.availableForWrite()>0，导致首帧的蓝牙部分永远无法发送，后续帧也被挡住。上传后，串口监视器选择115200和“新行”，应每秒看到 D,3,...；发送 C,1,101,STATUS 应收到 A,1,101,OK，再测试网页连接。

## 6. 历史记录

湿度纵轴默认0～20%，可切换0～50%或0～100%。超出刻度的样本计数会显示在图旁，顶部橙色三角可悬停查看真实湿度；完整刻度可查看全貌。图表抽样保留分段峰值与谷值，缩放不修改历史记录和CSV。浇水期间使用贯穿湿度绘图区的半透明蓝色背景区域：从收到开启状态至同一连续记录中的关闭状态；断连或采样缺口处截断，末尾仍开启时仅画到最后一条记录。区域依据控制输出记录，不代表水流反馈。

IndexedDB 保存收到的样本和操作/状态变化事件，携带固定 real 来源、会话、设备名、浏览器接收时间。沿用原数据库和索引，旧真实记录可继续查询；旧演示记录留在原库中，但不再显示或导出，旧来源选择偏好不再读取。刷新保留，清除站点数据会删除。未连接/未运行页面期间不写虚构记录；会话变化或超过3.5秒间隔在图上留空。图表抽样降低绘制开销，CSV 导出所选范围全部真实样本。

可查最近5/15分钟、1/6/24小时或自定义起止日期时间，事件显示该范围最新40条。CSV 为 UTF-8 BOM，保留原有ADC、换算值、模式等列，保留“估算照度lux”列，末尾追加雨水ADC、雨水状态、干燥确认剩余毫秒；旧记录的雨水列留空，无效换算值留空。旧记录的光照ADC也按当前公式生成lux曲线和导出值，不改写数据库；旧土壤湿度保留当时固件结果。时间依赖电脑时钟，运行毫秒来自 Nano。存储失败显示错误但控制/急停可用。长期使用请定期导出并关注浏览器存储空间，本版不自动删除历史。

## 8. 仍需实物验收

软件检查不能代替实际蓝牙和水路验证。温度公式需实测对照；HC-08底板供电、电磁阀驱动/电源仍需核实，当前雨水已配置，待验证现场灵敏度。实物到位后验证：

- 已配置雨水干湿ADC；实测滴水时自动/手动立即停水，连续干燥60秒才解除限制，中途再湿重新计时。
- 实际传感器变化在正常连接下2秒内显示，核对UUID/通知/写入。
- 受控条件下测试自动、手动、正常停止、急停、故障恢复和实际输出。
- 关闭页面后自动继续，手动在最后心跳后5秒期限内停止。
- 十次真实断连重连不冻结、不重放旧开阀命令；刷新历史、核对CSV。
- 受控条件下真实连续运行24小时，记录异常、强制超时与数据缺口。
